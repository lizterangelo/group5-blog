## 0 AWTA for Keeping our Secrets Safe?

Imagine passing a secret note in class, but instead of writing it in plain English, you encrypt it so only your friend can read it. Even better—you stamp it with a digital signature so your friend knows for sure that it came from you and not some impostor trying to stir up drama.

 That’s the power of cryptography in action, ensuring **CIA**:

* **Confidentiality**: The message stays private (RSA-OAEP encryption).
* **Integrity**: No one can tamper with it undetected (digital signature).
* **Authenticity**: The recipient knows it’s from you (signing key).

For this task, we implement an encrypt-then-sign approach using cryptographic libraries, ensuring both secrecy and authenticity without rolling our own crypto. Our program will:

* Generate separate key pairs for encryption and signing.
* Encrypt a short ASCII message (≤140 characters) using RSA-OAEP.
* Sign the encrypted message for authenticity.
* Verify the signature before decrypting to ensure message integrity.

By the end, we’ll have a secure way to share messages—no spills, no leaks, just cryptographic assurance. Now, let’s dive into the implementation!

## 1 Setup: Install Dependencies

We used Python’s powerful cryptography library to safely handle all encryption, decryption, signing, and verification tasks.

```python
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes, serialization
import base64
import os

```

## 2 Key Generation: Encryption and Signing

To achieve the Encrypt-Then-Sign scheme, we generated two key pairs:

1\. Encryption Key Pair (used for RSA-OAEP):

* Encrypts the message with the public key
* Decrypts it with the private key

2\. Signing Key Pair (used for RSA-PSS):

* Signs with the private key
* Verifies with the public key

```python
def generate_rsa_keypair():
    """Generate an RSA key pair (private & public key)."""
    private_key = rsa.generate_private_key(
        public_exponent=65537,
        key_size=2048,
    )
    public_key = private_key.public_key()
    return private_key, public_key


def save_key(key, filename, is_private=False):
    """Save RSA keys to a file."""
    if is_private:
        pem = key.private_bytes(
            encoding=serialization.Encoding.PEM,
            format=serialization.PrivateFormat.PKCS8,
            encryption_algorithm=serialization.NoEncryption(),
        )
    else:
        pem = key.public_bytes(
            encoding=serialization.Encoding.PEM,
            format=serialization.PublicFormat.SubjectPublicKeyInfo,
        )


    with open(filename, "wb") as f:
        f.write(pem)


def load_key(filename, is_private=False):
    """Load RSA keys from a file."""
    with open(filename, "rb") as f:
        key_data = f.read()
    if is_private:
        return serialization.load_pem_private_key(key_data, password=None)
    return serialization.load_pem_public_key(key_data)


```

All keys are securely generated and saved to .pem files. Future runs can load them back to avoid regenerating every time.

## 3 Encrypting the Message (RSA\_OAEP)

To ensure confidentiality, we encrypt the message using RSA-OAEP (Optimal Asymmetric Encryption Padding). Why OAEP? It enhances the basic RSA with semantic security to guard against chosen ciphertext attacks.

```python
def encrypt_message(message, public_key):
    """Encrypts a message using RSA-OAEP."""
    ciphertext = public_key.encrypt(
        message.encode(),
        padding.OAEP(
            mgf=padding.MGF1(algorithm=hashes.SHA256()),
            algorithm=hashes.SHA256(),
            label=None,
        ),
    )
    return base64.b64encode(ciphertext)  


```

Then, we encode the result in Base64 so it's easy to store, send, or print. This ensures that only the recipient (who has the private key) can decrypt the message.

## 4 Signing the Encrypted Message (RSA-PSS)

Once the message is encrypted, we sign the ciphertext to ensure authenticity and integrity. This means if someone tries to tamper with the ciphertext—even one bit—the signature check will fail.

We use RSA-PSS with SHA-256, a modern and secure signing scheme:

```python
def sign_message(ciphertext_b64, private_key):
    """Signs the raw encrypted message (bytes) using RSA-PSS."""
    ciphertext_bytes = base64.b64decode(ciphertext_b64)  
    signature = private_key.sign(
        ciphertext_bytes,
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH,
        ),
        hashes.SHA256(),
    )
    return base64.b64encode(signature)

```

## 5 Verifying the Signature Before Decrypting

*This is a crucial step*. We verify the signature before decrypting. If the signature is invalid, we stop. No decrypting tampered tea.

```python
def verify_signature(ciphertext_b64, signature_b64, public_key):
    """Verifies the signature against the raw ciphertext bytes."""
    ciphertext_bytes = base64.b64decode(ciphertext_b64)  # Convert Base64 → bytes
    signature_bytes = base64.b64decode(signature_b64)  # Convert Base64 → bytes


    try:
        public_key.verify(
            signature_bytes,
            ciphertext_bytes,
            padding.PSS(
                mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH,
            ),
            hashes.SHA256(),
        )
        return True
    except Exception as e:
        print(f"Signature verification failed: {e}")
        return False


```

## 6 Decrypting the Message (Only If Verified)

Once verification is successful, the receiver decrypts the message using the private key:

This restores the original message in a secure manner.

```python
def decrypt_message(ciphertext, private_key):
    """Decrypts a message using RSA-OAEP."""
    plaintext = private_key.decrypt(
        base64.b64decode(ciphertext),
        padding.OAEP(
            mgf=padding.MGF1(algorithm=hashes.SHA256()),
            algorithm=hashes.SHA256(),
            label=None,
        ),
    )
    return plaintext.decode()
```

Only the intended recipient with the private key can read it. Confidentiality unlocked.

## Full Secure Messaging Workflow

1\. Sender:

* Encrypts the message using the recipient's public key.
* Signs the encrypted message using their private signing key.
* Sends both the ciphertext and the signature.

2\. Receiver:

* Verifies the signature using the sender's public signing key.
* If valid, decrypts the ciphertext using their private key.

No signature? No decrypt. No authenticity? No trust.

### Why This Approach?

This ***Encrypt-Then-Sign*** method is superior because:

* If the signature is invalid, decryption is never attempted, preventing unnecessary computation and attacks.
* Ensures both confidentiality and authenticity in one robust system.
